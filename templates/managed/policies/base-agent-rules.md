# Base Agent Rules

1. Read the vault root instructions before changing project content.
2. Treat `sources/` and explicitly private/raw records as immutable unless the user requests a derived copy.
3. Separate source facts, reviewed notes, outputs and AI inference.
4. Run a dry-run before migration, archive, upgrade, overwrite or deletion.
5. Never copy personal vault content into the public control or skills repositories.
6. Ask only for decisions the Agent cannot safely infer; discover paths and run read-only checks automatically.
