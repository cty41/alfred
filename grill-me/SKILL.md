# Grill Me

User-facing entry into the grilling interview. This skill only routes: run the
`grilling` skill's workflow (ground the design tree, compute the frontier, ask
decision-ready questions in numbered rounds, finish at the shared-understanding
gate).

Invocation boundary: the user asks explicitly to be grilled/stress-tested. Never
start the interview unprompted, and never route here from ordinary planning or
review work.
