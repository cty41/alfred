# Confirmation policy

## Automatic

- Path discovery
- Quick doctor
- Link checking
- Privacy scan
- Dry-run generation

## One preview confirmation

- Initialize/link a vault
- Create or update ordinary Markdown/HTML
- Ingest a reviewed source
- Upgrade kit-owned files
- Archive a project
- Create a backup

## Separate explicit confirmation

- Delete or overwrite existing user-owned content
- Publish or push anything to a remote repository
- Move raw private records
- Store credentials or identity records in a synced location
- Commit a transaction or other irreversible external action
