## [S1] Problem

现有嘉里建设报告确认公司以约0.24倍NAV交易，但结论将“值得观察”和“缺乏经典清算安全边际”混在一起，未直接回答当前价格是否值得考虑买入，也未区分公司层面的期望回报与组合层面的仓位控制。用户另提供现代百货H&S案例；核验确认历史标的是005440，069960是其持有的分拆百货公司。

## [S2] Design

1. 核验现代百货H&S案例的公司沿革、历史财务数字、李录关联及来源等级；把可验证事实、可信二手叙述和无法核验部分分开。
2. 将嘉里建设结论拆成三个层级：
   - 估值：正常情景是否低估；
   - 安全边际：压力情景是否限制永久损失；
   - 组合角色：在尾部风险存在时应是观察仓、一般仓还是核心仓。
3. 鉴于公开资料无法严格桥接合并物业、少数股东和联营合营底层资产，撤回所有基于混合口径SOTP的精确值；改用归母NAV实现率10%/25%/45%/65%构造概率敏感性。明确现价等于24.4%归母NAV，概率表仅回答条件关系，不证明实际概率。
4. 给出明确、可证伪的结论：是否值得考虑买入；若是，适合何种仓位角色；哪些财务与经营信号支持加仓、停止加仓或退出。
5. 区分2011年开业的浦东嘉里城（Shanghai Pudong Kerry Parkside）与2026年Q2开业的PRISMA新嘉中心（Shanghai PRISMA），更正出租率、项目状态和在建管线归类；将PRISMA的强招商和客流视为尚未进入稳定期NOI的上行证据，不重复增加已经通过联营合营权益包含在归母NAV中的项目价值。
6. 修订 `research/kerry-properties-value/REPORT.md`，保留非个性化投资建议声明，并标注行情时点。
